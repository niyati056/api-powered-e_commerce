# Api-powered-ecommerce
Technologies: HTML5, CSS3, JavaScript (ES6+), Tailwind CSS, Google Gemini API, REST APIs, LocalStorage State Architecture.
Developed a responsive, multi-page e-commerce web platform featuring real-time catalog search, multi-attribute filtering, dynamic price adjustments, and persistent cart/wishlist management.
Integrated Google Gemini 2.5 Flash API with custom prompt grounding and RAG principles to build an in-store conversational AI assistant capable of contextual product recommendations.
Implemented client-side authentication, coupon discount algorithms, and multi-stage checkout flows with automated order ID generation and receipt rendering.
Engineered an offline fallback engine ensuring 100% platform uptime and graceful degradation during network interruptions or API rate limits.
